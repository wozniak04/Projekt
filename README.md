  # 💊 Medicine Knowledge Base & Voice Assistant
    > 🎓 **Technical High School / Early Educational Project**

    A web-based project built using PHP and JavaScript. It serves as a knowledge base for medications and uniquely
  integrates a voice assistant feature. It was created in my early educational journey to explore web development,
  backend logic, and basic API integrations.

    ## 🛠️ Tech Stack
    * **Backend:** PHP
    * **Frontend:** JavaScript, HTML, CSS
